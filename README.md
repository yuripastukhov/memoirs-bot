# Бот «Мемуары» — AI-помощник для написания воспоминаний

Telegram-бот, который помогает человеку написать мемуары: задаёт вопросы, собирает
истории, улучшает текст с помощью DeepSeek и сохраняет главы по пользователям.

## Что умеет

- пошаговое интервью: детство, семья, работа, важные события;
- улучшение текста: стили «как есть», «литературно», «кратко»;
- голосовые сообщения — распознавание речи и превращение в текст;
- хранение глав в отдельных файлах по каждому пользователю;
- подписка и поддержка через ЮMoney.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

Создайте `.env` рядом с `bot25.py`:

```
TELEGRAM_BOT_TOKEN=...
DEEPSEEK_API_KEY=...
YOOMONEY_WALLET=...
```

Для голосовых нужен `ffmpeg` в `PATH` (используется `pydub`).

## Запуск

```bash
python bot25.py
```

На Windows удобнее `start_memoirs.ps1` — поднимает бота в фоне, пишет логи в `logs/`
и хранит pid в `logs/memoirs.pids.json`:

```powershell
.\start_memoirs.ps1        # запустить
.\start_memoirs.ps1 -Stop  # остановить
```

## Структура

```
bot25.py            — весь бот: хендлеры, FSM, работа с DeepSeek, ЮMoney
start_memoirs.ps1   — запуск/остановка, логи, pid-файл
requirements.txt    — зависимости
.env.example        — пример переменных окружения
memoirs_bot_data/   — данные пользователей (создаётся автоматически, в git не хранится)
```

## Безопасность

Ключи и токены **не хранятся в коде** — только в `.env`, который не попадает в репозиторий.
Если вы форкнули проект со старыми версиями файлов, перевыпустите токен бота и ключ API:
они могли утечь.
